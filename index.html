02 / 上手

从一个终端开始。

使用官方仓库

echo 'https://github.com/Gozjaro/gozjaro-repo/releases/download/stable' > /etc/gozpak/repos.conf
gozpak sync
gozpak get curl

从源码构建系统 gozjaro-bootstrap

sudo ./build.sh 00-host-check
sudo LFS_PART=/dev/sdXN ./build.sh 10-partition
sudo ./build.sh all            # 源码模式：编译约 80 个包

二进制模式 --mode binary 直接装预编译包，几分钟搞定。
